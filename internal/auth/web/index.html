Tripo-MCP Connexion sur ce PC

Connecter Tripo Studio

Relie ton abonnement à tes agents. Avec le cookie de connexion, les jetons se renouvellent automatiquement, même navigateur fermé.

Dans ton navigateur habituel

Garde cette page ouverte pendant le transfert.

  1. Ouvre ta session Studio

    Connecte-toi à Tripo avec ton compte habituel.

    Ouvrir Tripo Studio dans un nouvel onglet

  2. Copie une requête

    Appuie sur F12, ouvre Réseau / Network et filtre sur team/list. Actualise Studio pour afficher la requête.

    Fais un clic droit sur la requête vers api.tripo3d.ai/v2/studio/team/list, puis Copier → Copier comme fetch ou cURL.

  3. Copie le cookie de connexion

    Dans les outils de développement, ouvre le stockage des cookies du domaine Tripo et copie la valeur de ory_kratos_session.

    Chrome / Edge
    Application → Cookies
    Firefox
    Stockage → Cookies

Transférer la connexion

Les données restent dans ce formulaire jusqu’à leur vérification.

La commande n’est jamais exécutée. Seuls les en-têtes Tripo nécessaires sont extraits.

Permet le renouvellement automatique. Sans cookie, la connexion expire avec le jeton temporaire.

Connexion établie

Tu peux fermer cette page et reprendre avec ton agent.

Après vérification, la connexion est chiffrée par Windows sur ce PC. Ne partage ni la requête ni le cookie dans un chat ou un dépôt.

Le lien local est valable 15 minutes. Un nouveau transfert sera nécessaire si Tripo expire ou révoque la session principale.
